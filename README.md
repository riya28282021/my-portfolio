# Riya Jamgaonkar — Pink & White Portfolio

A multi-page portfolio website with a handmade editorial look: strawberry pink, white, blush panels, playful stickers, animated CSS art, and a small interactive playground.

## Pages
- `index.html` — home / introduction
- `about.html` — bio, toolkit and education
- `experience.html` — Apple selection and resume-based work experience
- `projects.html` — Cloud DevOps, GamerVenture and Crop Disease Detection
- `playground.html` — interactive CSS blob and learning-video corner
- `contact.html` — contact links and an email-preparation form

## Run locally
1. Unzip this folder.
2. Open the folder in VS Code.
3. Open `index.html` using Live Server, or double-click the HTML file.
4. Internet is needed for Google Fonts and embedded YouTube playback. Most styling and animations are local.

## Edit
- Change colors, layout and responsive behavior in `style.css`.
- Change copy and page sections in the corresponding `.html` file.
- Change navigation, color-playground buttons and contact email form in `script.js`.
- Company logos are in `assets/`.
- Contact form opens the visitor's email app; it does not send or store messages itself.

## Publish with GitHub Pages
Create a separate repository for the portfolio, upload all six HTML pages plus `style.css`, `script.js`, and the `assets` folder to the repository root. Then open **Settings → Pages → Deploy from a branch**, choose `main` and `/(root)`, and save.

## Accuracy notes
Experience descriptions are based on the resume supplied. Apple is shown as selected for Retail, not as a completed employment period. Crop Disease Detection is marked as in progress. The GamerVenture dashboard numbers are illustrative visual mockup values.
